# Reference: Presentation Design Standards

This document defines the visual standards, color palettes, and typography for high-end presentations.

## 🎨 Design Philosophy

### Before Starting
- **Pick a bold, content-informed color palette**: The palette should feel designed for THIS topic.
- **Dominance over equality**: One color should dominate (60-70% visual weight), with 1-2 supporting tones and one sharp accent.
- **Dark/light contrast**: Dark backgrounds for title + conclusion slides, light for content ("sandwich" structure).
- **Commit to a visual motif**: Pick ONE distinctive element and repeat it (e.g., rounded image frames, icons in colored circles).

## 📐 Layout & Composition

**Every slide needs a visual element** — image, chart, icon, or shape.

- **Two-column**: text left, illustration on right.
- **Icon + text rows**: icon in colored circle, bold header, description below.
- **2x2 or 2x3 grid**: image on one side, grid of content blocks on other.
- **Half-bleed image**: full left or right side with content overlay.
- **Stat callouts**: big numbers (60-72pt) with small labels below.

## 🚫 Hallmarks of Bad Design
- **NEVER use accent lines under titles** — these are a hallmark of AI-generated slides.
- **Don't repeat the same layout** — vary columns and cards.
- **Don't center body text** — left-align paragraphs.
- **Don't skimp on size contrast** — titles must be significantly larger than body text.
- **Don't forget text box padding** — align elements to the visual edge of text.
