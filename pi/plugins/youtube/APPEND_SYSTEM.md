# Pi youtube bridge — selected project only

Apply this guidance only when the project explicitly opts into `optional_plugins/youtube`. The three YouTube skills provide domain instructions, not command handlers or isolated workers. Pi advertises each skill by its absolute location; load the selected skill only when the actual task warrants it.

The configured read-only `scribe` child is limited to `/explain`; it is **not** a YouTube scriptwriting/metadata worker. Do not claim a creative-director or YouTube specialist dispatch, or that `/pack` and `/script` route to scribe. An approved script or metadata draft can be produced in the main session with the relevant skill, then reviewed by the configured report-only auditor using raw evidence where appropriate. The deferred `/ideate`, `/pack`, and `/script` Pi-native commands remain deferred: installing a skill is not a command port. No video or upload is created merely by loading this bridge.
