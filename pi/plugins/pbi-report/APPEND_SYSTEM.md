# Pi pbi-report bridge — selected project only

Apply this guidance only when the project explicitly opts into `optional_plugins/pbi-report`. Pi loads `powerbi-report` as instructions and exposes its absolute skill location; read references relative to that location, never from the consuming project's cwd. Discovery alone does not apply a Power BI theme, create a report, or verify visual performance.

The `creative-director` child named by the source skill is **not configured** in the three-role Pi pilot. A user-approved layout brief and any Power BI editing belong in the main session unless a supported pilot child route is explicitly invoked. The report-only auditor may inspect orchestrator-captured raw evidence but cannot run Power BI or edit report files. Do not claim a specialist dispatch or an audit PASS from skill loading. No user-level Pi install or deployment follows from this bridge.
