## Judgment Calls

### A. VP-04 deviation (explicit ratio/keyword OR structural proxy) — **Acceptable, with a required follow-up**

Grep confirms: Slide B contains zero occurrences of "contrast"/"legib"/"accessib"; Slide A contains
two **incidental** occurrences ("low contrast" describing a napkin sketch's visual weight, "Keep it
legible" describing JSON text density) — neither is a formal accessibility statement about a
text/background pair. Neither gold makes an explicit ratio or accessibility declaration in the
sense the plan's D1 wording intended. The coder's resolution (explicit ratio/keyword OR a
structural proxy of background-statement + ≥2 distinct hexes) is a defensible application of the
plan's own embedded philosophy ("fix the validator, not the reference").

**Two issues found, neither blocking the code itself:**
1. The in-source comment is factually imprecise: it states "neither reference-slides.md gold
   prompt states... the words contrast/legible (verified against Slide B)" — this is true for
   Slide B only; Slide A does contain both words incidentally. The comment's own parenthetical
   ("verified against Slide B") technically self-limits the claim, but the topic sentence
   overclaims "neither." **LOW severity** — fix the comment wording to avoid a future reader
   trusting a claim that a 30-second grep contradicts.
2. The structural proxy doesn't validate any ratio — it only confirms colors are named. Actual
   ratio math is (correctly) deferred entirely to `contrast_check.py` against `LAYOUT_SPEC.md`.
   This is fine as designed, but it means VP-04's "contrast" signal is weaker than plan D1's literal
   wording implied.

**Ruling:** Acceptable to ship as-is for this phase's code metrics. Not phase-blocking. **Required
before the Plan can be considered fully reconciled:** the strategist (Plan owner, not auditor) must
add a one-line D1 amendment in `VSE-1-Plan.md` recording the OR-structural-proxy resolution, since
this changed the literal D1 contract. This is documentation debt, not implementation debt.

### B. `vse1_templates_1` deferral to BACKLOG — **Correct for THIS phase's scope; re-classified HIGH; must not be indefinitely deferred**

The templates file (`slide-prompt-templates.md`) is explicitly **not** on VSE-1's approved edit
list — editing it now would itself violate Hard Rule 3. Deferring the fix out of this phase is
therefore the *only* compliant option, and BACKLOG is the correct home per `orchestration.md`'s
Findings Protocol. **Not phase-blocking for T1–T4 closure.**

However: I re-classified the BACKLOG severity MEDIUM → HIGH (see BACKLOG addendum) because (a) it
is independently reproduced, not hypothetical, (b) `SKILL.md` Step 5 makes validation synchronous
and mandatory over every emission today, so this is a live blocker for the Grid-of-Cards archetype
right now, and (c) the root cause is Hard Rule 1 partial violation (see above), not merely "3
missing lines" — a pure template patch treats the symptom; the validator's archetype-blindness on
parts 2/8/9 is the disease. **Ruling:** acceptable to leave open at phase close, but recommend it be
scheduled as an immediate MTP-eligible fast-follow (single file, <30 lines) rather than folded
indefinitely into an open-ended "user to refine via Copilot iteration" bucket — and any fix pass
should also weigh whether VP-01 parts 2/8/9 need archetype-conditional logic, not just literal
line insertion into the 3 worked examples.
